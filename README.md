# MyPortfolioUdemy

## 📌 Proje Hakkında

MyPortfolioUdemy, ASP.NET Core MVC kullanılarak geliştirilen dinamik bir kişisel portföy web uygulamasıdır.

Projenin amacı; kişisel bilgilerin, eğitim hayatının, iş deneyimlerinin, yeteneklerin ve projelerin ziyaretçilere sunulabildiği bir portföy sitesi oluşturmaktır.

Ayrıca yönetim paneli sayesinde web sitesindeki içeriklerin veritabanı üzerinden yönetilebilmesi hedeflenmektedir.

## 🚀 Proje Özellikleri

- Dinamik kişisel portföy sayfası
- Hakkımda bölümünün yönetimi
- Eğitim ve deneyim bilgilerinin yönetimi
- Yetenek ve becerilerin listelenmesi
- Projelerin yönetimi
- Referansların yönetimi
- İletişim formu ve mesaj yönetimi
- Admin paneli üzerinden içerik yönetimi
- Veritabanı destekli dinamik içerikler

## 🛠️ Kullanılan Teknolojiler

| Teknoloji | Açıklama |
|---|---|
| C# | Backend programlama dili |
| ASP.NET Core MVC | Web uygulaması altyapısı |
| Entity Framework Core | ORM ve veritabanı işlemleri |
| Microsoft SQL Server | İlişkisel veritabanı |
| HTML5 | Sayfa yapısı |
| CSS3 | Tasarım ve stillendirme |
| JavaScript | İstemci taraflı işlemler |
| Bootstrap | Responsive arayüz tasarımı |
| Razor | Dinamik View yapısı |

## 🗄️ Veritabanı

Projede Entity Framework Core kullanılarak SQL Server ile veritabanı işlemleri gerçekleştirilmektedir.

Veritabanında kullanılan temel modeller:

- About
- Contact
- Experience
- Feature
- Message
- Portfolio
- Skill
- SocialMedia
- Testimonial

## 🎯 Projenin Amacı

Bu proje, ASP.NET Core MVC ve Entity Framework Core konularında öğrendiklerimi pekiştirmek, veritabanı işlemlerini uygulamalı olarak öğrenmek ve dinamik web uygulaması geliştirme deneyimi kazanmak amacıyla geliştirilmiştir.
